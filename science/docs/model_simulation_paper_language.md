# Phase 2M-LIT-2 Paper-Language Guardrails

## Current allowed language

- "A literature-provenance audit was conducted for the model dependencies."
- "Twelve of 21 dependencies currently have direct or derived traceability; the paper-candidate model configuration is not yet complete or frozen."
- "The long-downhill case is a literature-defined simulation benchmark, not a surveyed road."
- "The communication evidence is field measured, but its transfer to the selected heavy-truck model is not yet validated."

## Language allowed only after the strict gate passes

- "literature-calibrated physics-based simulation"
- "parameters were obtained or derived from published heavy-duty vehicle studies and manufacturer specifications"
- "model-based numerical validation"

## Prohibited language on current evidence

- "experimental vehicle validation"
- "real-vehicle validated"
- "field validated"
- any statement that `Reference_Truck` or a literature-bounded variant is a single experimentally identified physical vehicle
- any statement that current DEBUG M1–M10 outputs are paper evidence

The manuscript's scientific result tables and performance claims are unchanged in Phase 2M-LIT-2.
