# Approved Linux/WSL/VM environment

This specification prepares Phase 2C-1.5 without changing MAPPO or safety-controller semantics. CPU PyTorch is sufficient for Phase 2C-1.5 migration validation and Phase 2C-2 DiffQP correctness validation. CUDA is optional.

## Prerequisites

- approved Linux, WSL2, or Linux VM;
- Python 3.12 and its `venv` module;
- a C/C++ runtime supplied by the distribution;
- network access to the official PyTorch wheel index and PyPI.

The existing hard-QP forward solver is repository-local Python and has no external solver-package dependency. A future DiffQP library must not be selected or pinned until Phase 2C-2 explicitly registers it.

## Installation

From the repository root:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
```

Install PyTorch from the command generated by the official PyTorch selector for the target platform. For CPU validation, the unversioned official command is:

```bash
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
```

For an approved CUDA host, use the official selector rather than copying a CUDA version from another machine. No PyTorch version is pinned here because none has yet been verified in the target Linux environment.

Install the remaining locked/reference dependencies:

```bash
python -m pip install -r environment/linux/requirements.txt
```

Because PyTorch was installed first from the selected official index, the unpinned `torch` requirement is already satisfied and does not replace that platform-specific build.

## Required gates

```bash
python scripts/check_autodiff_backend.py
python scripts/run_regression_suite.py
```

Both commands must exit zero before Phase 2C-1.5 is restarted. The first gate performs real scalar autograd, `nn.Module` backward, and optimizer-step checks. The second runs exactly 12 reference tests, 5 Phase 2A tests, 5 Phase 2B tests, and 5 Phase 2C-1 tests, failing immediately on the first regression.

All DEBUG artifacts remain `paper_eligible=false`. These gates do not authorize publication experiments or DiffQP implementation.
